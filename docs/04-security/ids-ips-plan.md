# Kế hoạch IDS/IPS

**Chủ trì:** TV3. **Trạng thái:** BASELINE / CHƯA NGHIỆM THU.

Yêu cầu nâng cao trong [A] tr.4 áp dụng chương trình kỹ sư tài năng: security plan, firewall/ACL, IDS/IPS và best-practice guide. Đề in IDS/ISP; cần phân biệt IDS phát hiện với IPS ngăn chặn.

Chưa triển khai IDS/IPS. TV3/TV4 phải kiểm khả năng nền tảng trong tuần 1, chọn môi trường chạy thực nếu yêu cầu áp dụng; ACL không thay cho bằng chứng IDS/IPS.

- [ ] Xác định phạm vi chương trình áp dụng và mục tiêu phát hiện/ngăn chặn.
- [ ] Chọn công cụ/image được phép dùng, vị trí sensor và luồng được quan sát.
- [ ] Xác định chữ ký, tình huống kiểm thử lab, expected alert/drop và positive control.
- [ ] Lưu log/ảnh, cấu hình, phiên bản và ảnh hưởng throughput khi bật kiểm tra.
